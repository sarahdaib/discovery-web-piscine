Git Workflow

1. Edit
I created and edited the project files.

2. Add
I used the following command to stage the changes:
git add README.md git_workflow.txt

3. Commit
I saved the changes in Git history with:
git commit -m "Add project documentation"

4. Push
I uploaded the commit to GitHub with:
git push -u origin main

This workflow allows me to track changes locally and keep the project updated on GitHub.
